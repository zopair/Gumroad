## Product quality standard

- Deliverable matches the title, description and preview.
- Download files are editable, useful and tested in common applications.
- Provide a clean Start Here guide and a realistic example where appropriate.
- Add blank and example versions when the product benefits from them.
- Use spreadsheet formulas, dropdowns and dashboards when they materially improve the buyer's task.
- Include an exact file list, compatibility notes, limitations and setup steps.
- No unsupported guarantees, fake social proof, copied assets or keyword stuffing.
