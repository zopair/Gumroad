Setup

★Activation

Demo mode works right away. Enter your license key to unlock full rendering on your GitHub account.

1Your GitHub account

GitHub is free. Your videos render on your own account, so you control everything.

Create free GitHub account

Paste your profile link (we create a private “relaymind-studio” repo) or an existing repo link.

2Create your access key

Opens GitHub with the right boxes already ticked. Choose an expiry, scroll down and press “Generate token”, then copy it.

Open GitHub key page

3Paste key & connect

Paste the key and press Enter. We prepare your repo automatically.

4Delivery (optional)

Get every finished video sent to Telegram automatically. Create a bot with @BotFather and get your numeric chat ID from @userinfobot.
