# DocuSense Support

> Find the passage before you write the answer.

**SEO title:** DocuSense Support | PDF Evidence Search  
**Meta description:** Search supplied document passages and retrieve relevant evidence with document and page references. Designed for transparent support workflows.  
**Primary keyword:** PDF document search assistant  
**Tags:** PDF search, document knowledge, support operations, evidence retrieval, document Q&A

## The problem

Support and operations teams waste time searching long documents and risk answering from memory instead of the source.

## What this product does

Rank supplied document passages by visible term overlap and return matching excerpts with document and page metadata.

## What is included

- Multi-document text input
- Evidence passage retrieval
- Document and page references
- Insufficient-evidence fallback
- Structured answer report

## Frequently asked questions

### Is this semantic RAG?

Not in the local baseline. It uses transparent lexical retrieval.

### Does it extract text from PDFs?

The current runtime accepts extracted text and page metadata; PDF parsing and OCR are not included.

### Can it answer without evidence?

It reports insufficient evidence when no relevant passage is found.
