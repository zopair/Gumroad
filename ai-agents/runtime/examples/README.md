# Safe sample inputs

Each JSON file is a synthetic example intended for local demonstration only. URLs use example.com placeholders and are not evidence of real companies or services.

Run a sample from the runtime directory with:
- jarvis-agents run docusense-support --input examples/docusense.json
- jarvis-agents run tradetrend-analyst --input examples/tradetrend.json
- jarvis-agents run socialsync-ai --input examples/socialsync.json

The same pattern applies to the remaining agent slugs. Do not treat sample outputs as market, legal, financial, or security advice.
