# JARVIS AI Agents — Store Release Plan

## Existing storefront protection

The current live catalog is documented in the root `CATALOG.md`. Do not overwrite, rename, unpublish, reprice, or replace any existing live product as part of this development branch.

Gumroad listing creation is outside the scope of this branch until the product ZIP, images, copy, price, support policy, and owner approval are ready.

## Commercial asset set required per product

1. Square thumbnail (minimum 600×600 px; verify Gumroad's current upload guidance before publishing).
2. Wide cover image (product-specific; design target 1280×720 px).
3. Three to five screenshots of the real, tested interface.
4. One short demo recording or animated preview generated from the real product.
5. Listing title, concise value proposition, detailed feature list, requirements, limitations, and support policy.
6. Exact downloadable ZIP and versioned checksum.
7. Refund/support wording consistent with store policy and applicable law.

## Listing copy requirements

- Describe what the current build actually does.
- State required operating system/runtime and whether an API key is required.
- State third-party service costs and data handling.
- Explain setup time and included files accurately.
- Do not claim guaranteed SEO rankings, guaranteed leads, profits, legal correctness, perfect security, or guaranteed social reach.
- Do not use fake reviews, fake customer counts, or fabricated usage metrics.

## Release order

Prioritize a focused pilot with DocuSense Support, MailForge Pro, and RankMaster AI after source qualification. Continue only after the first release passes clean-install, usability, support, and customer-value review. The remaining seven products follow the same release gates.

## Owner approval

Before any Gumroad listing is created or changed, present the final product build, exact ZIP manifest, license audit, images, copy, proposed price, and support requirements for explicit approval.
